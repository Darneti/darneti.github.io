# 📖 Darneti.github.io

> Персональний блог з літературним творчеством - модернізований для веб-технологій 2026

## ✨ Особливості

- 🎨 Сучасний дизайн з градієнтами та glassmorphism ефектами
- 📱 Повністю адаптивна верстка (mobile-first)
- 🌙 Темна тема з яскравими акцентами
- ⚡ Плавні анімації та transitions
- 📝 Коротке оповідання "Правда про долю потрапленця"
- 💬 Сучасна форма з real-time валідацією
- 🔔 Toast notifications замість alert()
- 🔝 Кнопка швидкого повернення (IntersectionObserver API)
- ♿ WCAG 2.1 compliant (доступність)
- 🔍 SEO оптимізація (robots.txt, sitemap.xml)
- 🚫 **Без jQuery!** (268KB економії)

## 🛠 Технології

### HTML5
- Семантичні теги (`<nav>`, `<main>`, `<footer>`)
- ARIA атрибути для accessibility
- Modern form elements

### CSS3
- CSS Grid layout (готується)
- CSS Custom Properties (змінні)
- Modern Flexbox
- Backdrop filters
- CSS animations
- `@media (prefers-reduced-motion)` підтримка
- `focus-visible` для accessibility

### JavaScript (Vanilla ES2024)
- ✅ **Без jQuery!** Повністю переписано на vanilla JavaScript
- IntersectionObserver API для кнопки "Вгору"
- Real-time form validation
- Toast notifications system
- Keyboard navigation (Escape для закриття)
- ARIA attributes dynamic updates

### SEO
- robots.txt для пошукових систем
- sitemap.xml для індексації
- humans.txt з інформацією про проект
- Enhanced Open Graph meta теги (готується)

### Performance
- JavaScript: 4.3KB (було 272KB з jQuery)
- **98% економія JavaScript!**
- Оптимізовані шрифти (Google Fonts)
- WebP зображення підтримка (готується)
