# 📖 Darneti.github.io

> Персональний блог з літературним творчеством

## ✨ Особливості

- 🎨 Сучасний дизайн з градієнтами та glassmorphism ефектами
- 📱 Повністю адаптивна верстка (mobile-first)
- 🌙 Темна тема з яскравими акцентами
- ⚡ Плавні анімації та transitions
- 📝 Коротке оповідання "Правда про долю потрапленця"
- 💬 Форма зворотного зв'язку з валідацією
- 🔝 Кнопка швидкого повернення вгору

## 🛠 Технології

- HTML5
- CSS3 (Custom Properties, Flexbox, Animations)
- JavaScript (jQuery)
- Google Fonts

## 🎨 Кольорова схема

- Primary: `#00d4ff` (Cyan)
- Secondary: `#a855f7` (Purple)
- Accent: `#f472b6` (Pink)
- Background: `#0a0a0a` (Dark)

## 📦 Структура проекту

```
├── index.html          # Головна сторінка
├── main.css           # Стилі
├── main.js            # JavaScript
├── jquery-3.2.1.js    # Бібліотека jQuery
└── *.jpg              # Зображення
```

## 🚀 Запуск

Просто відкрийте `index.html` у браузері або перегляньте на GitHub Pages:
https://darneti.github.io
